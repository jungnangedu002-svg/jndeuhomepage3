# 단과반 프로그램 안내 페이지

엑셀 자료(단과반 시간표 · 단과반 현황 · 프로그램 소개 · 프로그램 사진)로 만든 정적 웹페이지입니다.

- `index.html` — 페이지 내용 (시간표, 모집 현황, 프로그램 소개)
- `style.css` — 디자인
- `apply.js` — 수강 신청 창과 메일 발송
- `photos/` — 프로그램 사진을 넣는 폴더 (아래 표의 파일 이름으로 넣으면 자동으로 표시)
- `progress/` — 제작 과정 스크린샷

빌드 과정이 없는 정적 사이트라 Vercel에 그대로 배포됩니다.
모집 인원이 바뀌면 `index.html`의 "단과반 모집 현황" 부분 숫자와 막대 너비(`width:33.3%` 등)를 고치면 됩니다.

## 사진 넣기

`photos/` 폴더에 아래 이름의 **.jpg** 파일을 넣으면 해당 프로그램 칸(과 상단 사진 칸)에 자동으로 나타납니다.
사진이 없는 칸에는 프로그램 이름이 적힌 빈 칸이 보입니다.

| 프로그램 | 파일 이름 |
|---|---|
| 일상생활지원 | `photos/daily-life.jpg` |
| 스마트 라이프 | `photos/smart-life.jpg` |
| 스텝업 | `photos/step-up.jpg` |
| 손끝 공예 | `photos/craft.jpg` |
| 요리 산책 | `photos/cooking.jpg` |
| 슬기로운 자립생활 | `photos/independent-living.jpg` |

상단에는 스마트 라이프 · 손끝 공예 · 스텝업 · 슬기로운 자립생활 사진이 함께 쓰입니다.
가로가 긴 사진(4:3 비율 정도)이 가장 잘 맞고, 칸에 맞게 가장자리가 잘려 보일 수 있습니다.

## 수강 신청 메일 (FormSubmit)

모집 현황 카드의 **신청하기**를 누르면 신청 창이 뜨고, 제출하면 FormSubmit 서비스를 통해
`jungnang2019@daum.net`으로 메일이 발송됩니다. (무료, 가입 필요 없음)

**처음 한 번 활성화**
1. 배포된 사이트(https://…)에서 신청서를 한 번 제출합니다. 화면에 "활성화되지 않았어요" 안내가 뜨면 정상입니다.
2. `jungnang2019@daum.net` 메일함(스팸함 포함)에 온 FormSubmit의 **Activate Form** 메일에서 버튼을 누릅니다.
3. 다시 제출하면 신청 메일이 들어옵니다.

**(선택) 메일 주소 가리기**
활성화 후 FormSubmit이 보내주는 메일에 무작위 문자열이 있으면, `apply.js`의 `FORM_ID` 값을 그 문자열로 바꾸세요.
페이지 소스에 메일 주소가 드러나지 않아 스팸을 줄일 수 있습니다.

**신청이 안 될 때**
- "메일 서비스(FormSubmit)가 지금 응답하지 않아요": FormSubmit 서버 장애일 수 있습니다. https://formsubmit.co 가 열리는지 확인하고 잠시 후 다시 시도하세요.
- 컴퓨터에서 `index.html` 파일을 바로 열면 메일이 가지 않습니다. 배포된 주소에서 시험하세요.
