# 단과반 프로그램 안내 페이지

엑셀 자료(단과반 시간표 · 단과반 현황 · 프로그램 소개 · 프로그램 사진)로 만든 정적 웹페이지입니다.

- `index.html` — 페이지 내용 (시간표, 모집 현황, 프로그램 소개)
- `style.css` — 디자인
- `apply.js` — 수강 신청 창과 메일 발송
- `photos/` — 프로그램 사진을 넣는 폴더 (아래 표의 파일 이름으로 넣으면 자동으로 표시)
- `progress/` — 제작 과정 스크린샷

빌드 과정이 없는 정적 사이트라 Vercel에 그대로 배포됩니다.
모집 인원이 바뀌면 `index.html`의 "단과반 모집 현황" 부분 숫자와 막대 너비(`width:33.3%` 등)를 고치면 됩니다.

## 사진 넣기

`photos/` 폴더에 아래 이름의 **.jpg** 파일을 넣으면 해당 프로그램 칸(과 상단 사진 칸)에 자동으로 나타납니다.
사진이 없는 칸에는 프로그램 이름이 적힌 빈 칸이 보입니다.

| 프로그램 | 파일 이름 |
|---|---|
| 일상생활지원 | `photos/daily-life.jpg` |
| 스마트 라이프 | `photos/smart-life.jpg` |
| 스텝업 | `photos/step-up.jpg` |
| 손끝 공예 | `photos/craft.jpg` |
| 요리 산책 | `photos/cooking.jpg` |
| 슬기로운 자립생활 | `photos/independent-living.jpg` |

상단에는 스마트 라이프 · 손끝 공예 · 스텝업 · 슬기로운 자립생활 사진이 함께 쓰입니다.
가로가 긴 사진(4:3 비율 정도)이 가장 잘 맞고, 칸에 맞게 가장자리가 잘려 보일 수 있습니다.

## 수강 신청 메일 (Web3Forms)

모집 현황 카드의 **신청하기**를 누르면 신청 창이 뜨고, 제출하면 Web3Forms 서비스를 통해
`jungnang2019@daum.net`으로 메일이 발송됩니다.

**처음 한 번 설정**
1. https://web3forms.com 에 접속해 `jungnang2019@daum.net`을 입력하고 **Create Access Key**를 누릅니다.
2. 그 메일함으로 온 액세스 키(예: `a1b2c3d4-....`)를 복사합니다.
3. `apply.js` 맨 위의 `WEB3FORMS_ACCESS_KEY = ''` 따옴표 안에 키를 넣고 저장·배포합니다.

액세스 키는 공개되어도 괜찮은 값입니다. 메일은 키를 만들 때 입력한 주소로만 발송됩니다.
